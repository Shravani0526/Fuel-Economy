# Fuel-Economy

## Overview
This project analyzes vehicle fuel economy data to understand how different factors such as engine size, cylinders, and vehicle class affect fuel efficiency. The goal is to extract meaningful insights and visualize trends using data science techniques.

##  Objectives
- Analyze fuel consumption patterns of vehicles  
- Identify factors affecting fuel efficiency  
- Perform data cleaning and preprocessing  
- Visualize relationships between variables  

##  Dataset
The dataset contains information about different vehicles, including:
- Engine size  
- Number of cylinders  
- Fuel consumption (city/highway)  
- CO₂ emissions  
- Vehicle class  

## Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

##  Key Analysis Performed
- Data cleaning and handling missing values  
- Statistical summary of dataset  
- Correlation analysis between features  
- Visualization of:
  - Fuel consumption vs engine size  
  - CO₂ emissions vs fuel consumption  
  - Distribution of vehicle classes  

##  Visualizations
- Scatter plots  
- Bar charts  
- Heatmaps  
- Distribution plots
